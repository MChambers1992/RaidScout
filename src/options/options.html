Scouting (WoWProgress & Raider.IO auto-open)

Scores the character through the API first and only opens their WarcraftLogs tab if they pass your thresholds — so rejected candidates never have to get through WarcraftLogs' Cloudflare check just to have their tab closed again. Needs API credentials; without them (or if a lookup fails) RaidScout falls back to opening the tab and checking afterwards. On by default.

Opens WarcraftLogs tabs without switching to them, so browsing a recruitment list isn't interrupted.

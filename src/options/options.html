API credentials

Create a v2 API client at warcraftlogs.com → Settings → Manage your API clients (any redirect URL works), then paste its ID and secret here. Parse scoring everywhere in RaidScout needs these.

Synced across your devices.

Parse thresholds

Set these once. They drive parse filtering on WoWProgress, Raider.IO and Guilds of WoW, the pre-flight check, and Scout.

Min best % Min median % DPS Tank Healer

Best is the highest single parse on any fight; median is the middle one. DPS and tanks are measured on damage, healers on healing — RaidScout picks the metric per character. Leave Tank blank to reuse the DPS row. Characters with no logs count as below every threshold; characters whose lookup failed are always kept, so a misconfiguration can never empty a page.

By default anyone with a single mythic kill is judged on mythic parses while everyone else is judged on heroic. Heroic only compares everyone on the same footing.

Ranks candidates by parse on every site with parse filtering on, mythic ahead of heroic.

Scouting

When you visit a candidate on WoWProgress or Raider.IO, score them through the API first and only open their WarcraftLogs tab if they pass — rejected candidates never have to clear WarcraftLogs’ Cloudflare check. If a lookup fails the tab opens and is checked again there; with no credentials every tab opens.

Opens WarcraftLogs tabs without switching to them, so browsing a list isn’t interrupted.

Scout

Gathers candidates from every site in one pass, merges duplicates, and ranks everyone by parse. Open it from the toolbar popup.

Sources

Each site is filtered by its own settings from the tabs above. WoWProgress is read over the network; the other two render in the browser, so Scout opens each briefly in a background tab and closes it again. WarcraftLogs isn’t a source — its recruitment page sits behind Cloudflare and its API has no recruitment data — it supplies the parses everyone is ranked by.

Run limits

Each candidate is one WarcraftLogs lookup. Around 150 keeps a run well inside the API’s hourly budget; cached scores make repeats nearly free.

Listing pages pulled per run and per “Load more”. WoWProgress only.
